# Model Mania 2001 v1 — Early Iteration

## Description
First iteration of the SolidWorks Model Mania 2001 challenge part. Constructs two isolated sub-components: a hollow angled cylinder positioned at 45° and a rectangular base block with two drilled mounting holes. Components are not yet assembled; this version serves as a structural skeleton before full integration in v2.

## Keywords
Model-Mania-2001, SolidWorks, cylinder, makeCylinder, makeBaseBox, angled-cylinder, hollow, mounting-holes, cut, translate, replicad, mechanical, parametric, reference-geometry

## Parameters
| Variable | Value | Unit | Meaning |
|----------|-------|------|---------|
| cylinderOuterRadius | 52/2 = 26 | mm | Outer radius of the hollow cylinder |
| cylinderInnerRadius | 32/2 = 16 | mm | Inner (bore) radius |
| cylinderHeight | 32 | mm | Length along cylinder axis |
| cylinderAngle | 45° | ° | Inclination of cylinder axis from horizontal |
| startPoint | [−146, 0, 64] | mm | Origin point of the cylinder axis |
| baseHeight | 20 | mm | Thickness of base block (X direction) |
| baseWidth | 96 | mm | Width of base block (Y direction) |
| baseLength | 64 | mm | Length of base block (Z direction) |
| holeSpacing | 60 | mm | Centre-to-centre distance between mounting holes |
| holeRadius | 6/2 = 3 | mm | Radius of mounting holes |
| holeMarginFront | 32 | mm | Z-offset of hole centres from base front face |

## Code
```javascript
const {draw,makeCylinder,makeBaseBox} = replicad

function main()
{
// Model Mania 2001 part 1

let startPoint = [-146,0,64];
let cylinderAngle = 45*Math.PI/180;
let cylinderDirection = [Math.cos(cylinderAngle),0,Math.sin(cylinderAngle)]
let cylinderHeight = 32;
let cylinderOuterRadius = 52/2;
let cylinderInnerRadius = 32/2

let cylinderOuter = makeCylinder(cylinderOuterRadius,
cylinderHeight,startPoint,cylinderDirection)
let cylinderInner = makeCylinder(cylinderInnerRadius,
cylinderHeight,startPoint,cylinderDirection)
cylinderOuter = cylinderOuter.cut(cylinderInner)

let baseHeight = 20;
let baseWidth = 96;
let baseLength = 64;
let holeSpacing = 60;
let holeMarginFront = 32;
let holeRadius = 6/2;

let baseBlock = makeBaseBox(20,96,64).translate([-baseHeight/2,0,0])
let holeCutter = makeCylinder(holeRadius,baseHeight*4,[0,-holeSpacing/2,holeMarginFront],[-1,0,0])
let holeCutter2 = holeCutter.clone().translate([0,holeSpacing,0])

baseBlock = baseBlock.cut(holeCutter).cut(holeCutter2) 

return [
{shape: cylinderOuter, color: "steelblue"}
,{shape:baseBlock, color: "red"}
]
}
```
